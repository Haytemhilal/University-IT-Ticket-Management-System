# University-IT-Ticket-Management-System

A full-stack IT support ticket management system built using ASP.NET Core, SQLite, HTML, CSS, and JavaScript. The application allows users to create, manage, update, and resolve technical support tickets through a responsive dashboard interface.

Features:
• Full CRUD operations for ticket management
• REST API development using ASP.NET Core
• SQLite database integration with Entity Framework Core
• Ticket status tracking (Open, In Progress, Resolved)
• Technician assignment and ticket management
• Interactive frontend dashboard using JavaScript
• API testing and documentation with Swagger
• Persistent data storage and backend architecture implementation

Technologies Used:
• ASP.NET Core Web API
• Entity Framework Core
• SQLite
• HTML / CSS / JavaScript
• Swagger
• REST APIs

This project was developed to simulate a real-world university IT support environment and strengthen backend, database, and full-stack development skills.
